Seventeen Syllables of Debugging — one haiku about debugging, three lines in the 5-7-5 syllable shape:

> an empty log line
> the cursor blinks at midnight
> the bug dreams of me

The log is empty, the cursor waits at midnight — and the last line turns it: the bug is no longer in the code, it is in the debugger's head, dreaming of them. This program writes that haiku to /output/entry.txt; a house judge compares the haikus two at a time, and the sharpest seventeen syllables take the prize.

Run it: `python3 main.py` (writes /output/entry.txt).
